# Curso: Introducción a Windows 11 🖥️
Plataforma web educativa e interactiva diseñada para la impartición de cursos de computación a distancia, estructurada bajo una metodología de aprendizaje progresivo y acceso dinámico autorizado.

## 👨‍🏫 Autoría y Dirección
* **Creador y Moderador:** H. Javier Rivas

## 📌 Características del Proyecto
* **Modalidad:** Aplicación web dinámica con control de acceso por clave individual.
* **Estructura Metodológica:** Lecciones fraccionadas en lapsos de una hora divididas en 4 momentos clave:
  1. **Teoría:** Fundamentos y objetivos del aprendizaje (~15 min).
  2. **Ejemplo:** Demostración práctica explicada (~10 min).
  3. **Ejercicio:** Práctica guiada para el alumno (~15 min).
  4. **Retroalimentación:** Comentarios del moderador, resolución de dudas y toma de notas (~20 min).

## 🚀 Despliegue (GitHub Pages)
Este proyecto está optimizado para ejecutarse de forma estática y dinámica a través de **GitHub Pages**. Puedes acceder a la interfaz principal del curso mediante el enlace configurado en el repositorio.
